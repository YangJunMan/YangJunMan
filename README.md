# 양준혁

사용하는 사람의 불편을 듣고, 필요한 도구를 만들어 운영합니다.
Linux·Windows Server와 업무 자동화를 공부하며, 구현 과정과 문제 해결 기록을 남기고 있습니다.

[이력서](https://www.yangjunman.com/resume) · [실험실](https://www.yangjunman.com/lab) · [블로그](https://www.yangjunman.com/blog)

## 프로젝트

### [Windows 권한 체험 랩](https://lab.yangjunman.com/winlab/)
파일 서비스의 권한·반출 통제 방식을 이해하기 위해 만든 Windows Server AD 랩입니다.
홈서버의 KVM 위에 구성했으며, 브라우저에서 역할별 파일 접근과 승인 과정을 체험할 수 있습니다.

### [회의록 만들기](https://lab.yangjunman.com/minutes/)
녹음이나 파일을 올리면 Whisper로 전사하고 LLM으로 요약하는 서비스입니다.
화자 구분과 참석자 이름 편집을 지원하며, 직접 사용하면서 기능을 개선하고 있습니다.

### [TokenBench](https://github.com/YangJunMan/claude-code-token-savings-benchmark)
Claude Code의 토큰 절약 기법을 같은 과제로 반복 측정한 개인 실험입니다.
측정 데이터와 비용 비교, 확인한 한계를 저장소와 대시보드에 정리했습니다.

### [내 집 찾기](https://github.com/YangJunMan/search_auction)
부동산 경매 정보를 조건과 지도로 살펴보는 웹 서비스입니다.
매물 검색, 지하철역과의 거리 확인, CSV 내보내기를 제공합니다.

### [서비스 상태 모니터](https://github.com/YangJunMan/service-uptime-monitor)
블로그와 실험실에 HTTP 요청을 보내 상태와 응답 시간을 기록합니다.
점검 결과는 [대시보드](https://yangjunman.github.io/service-uptime-monitor/)에서 확인할 수 있습니다.

## 사용한 기술

- **Linux · Windows Server**: 홈서버 운영과 AD 권한 랩
- **Python · PowerShell**: 회의록 처리와 강의자료 업로드 자동화
- **Git · GitHub Actions · Grafana · Confluence**: 변경 관리, 자동 측정, 모니터링, 문서 정리
